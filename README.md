 # Учёт посещения дополнительных занятий по математическому анализу
 
## Структура проекта

```bash
PythonProject2/           
├── .venv/ 
├── csv_data/ # Хранилище CSV-файлов 
├── data/ # Хранилище JSON-файлов 
├── src/
│ └── db/
│ ├── backend/
│ │ ├── init.py
│ │ ├── csv.py 
│ │ ├── database.py # Абстрактный интерфейс Database
│ │ ├── errors.py # Классы исключений
│ │ ├── file.py # JSON реализация
│ │ └── memory.py 
│ ├── init.py
│ ├── main.py # Точка входа
│ └── tui.py 
├── tests/
│ ├── init.py
│ ├── test_csv.py # Тесты CSV
│ ├── test_file.py # Тесты JSON
│ ├── test_main.py # Тесты точки входа
│ └── test_memory.py # Тесты in-memory
├── .gitignore
└── README.md
```
### Функции

- добавление записей о посещении доп.занятий по матану
- просмотр всех записей
- поиск с фильтрацией (по любому полю)
- обновление записей
- удаление записей (по фильтру или все)
- сортировка по любому полю (возрастание или убывание)
- обработка ошибок ввода и файловых операций
- переименование таблиц и колонок

#### Тесты

Покрытие кода тестами более 80%

- тестирование CRUD операций
- тестирование фильтрации
- тестирование сортировки
- тестирование обработок ошибок
- тестирование файловых реализаций (JSON, CSV)

##### Запуск
```bash
python -m src.db
```

###### Запуск тестов
```bash
pytest tests/ -v
```
